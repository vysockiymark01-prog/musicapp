# 🎼 Музыкальное приложение

Интерактивный тренажёр для учеников музыкальной школы. Работает прямо в браузере — без сервера, без установки.

**[Открыть приложение →](https://vysockiymark01-prog.github.io/musicapp/)**

---

## Модули

| Модуль | Описание |
|--------|----------|
| 🎼 Нотная грамота | Ноты на стане, ритм, длительности, построение интервалов |
| 🥁 Ритмический тренажёр | Группировка длительностей, правила бимования |
| 👂 Слуховой анализ | Интервалы, аккорды, лады на слух |
| 🎵 Музыкальные диктанты | Одноголосный, двухголосный, ритмический диктант |
| 🔢 Цифровка | Ступени, аккорды, кадансы — тренажёр |
| 🔑 Тональности | Квинтовый круг, ключевые знаки, гаммы, параллельные тональности |
| 🎹 Транспозиция | Перенос нот и гамм на интервал, викторина |
| 📖 Словарик терминов | Карточки, квиз, мэтчинг терминов |
| 🎭 Муз. литература | Композиторы, произведения, хронология, викторина |
| 💬 Цитатник | Мысли великих композиторов о музыке и творчестве |
| 🎷 Джазовая гармония | 12 стилей — блюз, свинг, бибоп, кул-джаз, латино-джаз, фьюжн и другие |
| 🎙 Тюнер | Настройка гитары, балалайки, домры — авто и ручной режим |
| 🎯 Метроном | Темп, размер такта, акцент, tap tempo |
| 🎼 Инструменты оркестра | Симфонический, народный, джазовый составы |
| ⭐ Избранное | Все сохранённые композиторы, произведения, инструменты, термины и цитаты в одном месте |

## Возможности

- 🌗 Светлая и тёмная тема
- 🌐 Русский и английский язык
- 📱 Адаптивный дизайн (телефон, планшет, компьютер)
- 💾 Настройки, прогресс и избранное сохраняются между сессиями
- 📊 Статистика прогресса — сколько разделов открыто
- 🏅 Достижения за прогресс и активность в приложении
- ⭐ Избранное — закладки на композиторов, произведения, инструменты, термины, цитаты, со сводной страницей
- 📤 Экспорт и импорт данных приложения в файл — для переноса между устройствами

## Запуск

**Локально** — скачайте репозиторий и откройте `index.html` в браузере.

**GitHub Pages** — форкните репозиторий, включите Pages в настройках (Settings → Pages → Branch: main), и приложение будет доступно по адресу `https://your-username.github.io/your-repo-name/`.
